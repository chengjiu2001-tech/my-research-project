计费口径

输入 Token 包含缓存读取 Token。按价格版本，分别计算非缓存输入、缓存读取与输出费用。缺少价格或 usage 的记录显示为“未知”。第一版只对已知计费维度估算。

Codex 订阅内的配额不属于 OpenAI API 账单；本看板只统计 API 计费调用。官方用量仅接入 completions 类别，其他 API 产品暂不统计 Token。
